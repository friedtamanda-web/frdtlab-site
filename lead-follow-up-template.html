Lead Follow-Up Automation Template

Use this free lead follow-up template to log form submissions in a spreadsheet, create Gmail drafts, and alert the person who owns each lead.

Setup steps

Route one form into a lead log, prepare an email draft, and notify the person who owns the follow-up. Start with a test lead.

  1. Trigger. Connect the form’s new-submission trigger in Make. Capture the submission ID, name, email, service requested, and submission time.
  2. Log. Search your lead sheet for that submission ID. Add a row only when it is new. Use these columns:
Submission ID, Received at, Name, Email, Service, Status, Draft ID, Alerted at, Owner
  1. Draft. Create a Gmail draft addressed to the submitter. Save the draft ID and set the row status to Ready for review. Keep sending manual.
  2. Alert. Send the owner the lead ID and a link to the lead sheet. Set Alerted at after delivery. On retry, resume at the first unfinished step. Check Gmail and the alert channel before rerunning a failed write-back.
  3. Test. Submit your own address, replay the same submission ID, and confirm one lead, one draft, and one alert. Then enable the scenario.

How to test the automation

Submit the same test inquiry twice with the same submission ID. The lead log should show one row, Gmail should contain one draft, and the owner should receive one alert. Try a different submission ID to confirm that a new inquiry gets its own row.
