Piece 1 · Top of every report

Data currency: read before quoting.

Before a single chart, the report says what was pulled today, how, and what wasn't. A number with no date and no source doesn't get quoted in a board meeting.

Data currency · read before quoting

  • New today: month-to-date paid search, read through the platform's own API. The latest three days are still filling in, so the return ratio will rise as it settles.
  • Store revenue: manual export from the store platform, pulled on the 5th. The store platform is the system of record. Analytics is not.
  • Not re-pulled today: two social platforms (no logged-in session this run) and the marketplace (latest is the monthly export). Their figures carry the older date.
  • Rankings: rank tool out of API credits this week. Latest ranks are from a manual read; analytics organic traffic is the live search signal.
  • Still not measurable: AI-assistant mentions, phone calls, one ad account not yet linked. Marked "awaiting data," never estimated.
